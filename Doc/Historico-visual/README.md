## Como registrar o próximo ajuste

1. A cada ajuste visível, abrir a próxima pasta numerada com uma descrição curta, por exemplo, `003-menu-avisos`. Preservar as capturas anteriores.
2. Capturar a tela afetada nos tamanhos em que a mudança se aplica. Usar nomes que identifiquem tela, dispositivo e, quando necessário, estado, como `menu-computador-aviso-visivel.png`.
3. Para comparar versões, repetir o cenário, tamanho de janela, zoom e tema. Registrar diferenças de condição e o instante capturado quando houver animação.
4. Acrescentar uma linha ao índice com data, mudança, links para o antes e o depois e o documento de decisões. Para mudanças apenas sonoras, registrar a verificação de áudio no documento da rodada.
