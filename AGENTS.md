# Instruções para IAs — Decifra

Antes de criar ou alterar código, modelos de dados, migrações, testes ou configurações deste projeto, leia e siga:

1. [Agents/Regras.md](Agents/Regras.md): regras de desenvolvimento e colaboração.
2. [Doc/Detalhes.md](Doc/Detalhes.md): regras de negócio e experiência do jogo.
3. [Doc/Planejamento-tecnico.md](Doc/Planejamento-tecnico.md): arquitetura e bibliotecas aprovadas.

Estas instruções se aplicam a todo o repositório. Mantenha as regras detalhadas em `Agents/Regras.md`, evitando cópias divergentes neste arquivo.

Todo código de autoria do projeto deve utilizar português, respeitando as exceções de compatibilidade descritas nas regras. Instruções explícitas do usuário prevalecem sobre as convenções deste repositório.
